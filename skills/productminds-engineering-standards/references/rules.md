# Rule Index

Productminds standards should be loaded progressively. Start here, then open only the detail file that matches the work.

## Rule Families

- `rules/domain-and-boundaries.md`: legal states, boundary validation, domain ownership, required infrastructure.
- `rules/graphql.md`: GraphQL nullability, scalars, unions, and domain type reuse.
- `rules/effect-and-services.md`: Effect happy paths, services, layers, external clients, and tests.
- `rules/frontend-and-rescript.md`: ReScript render style, component ownership, generated data, frontend ID parsing, keys.
- `rules/review-and-stacks.md`: review hygiene, deployable stack slices, and adding new standards.

Each rule-family file includes source links and small examples alongside the rules.
